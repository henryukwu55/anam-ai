# Anam AI Widget Test

A test page for Anam AI conversational widget with text input enabled.

## Features

- ✅ Floating chat widget
- ✅ Text input enabled
- ✅ Voice input enabled
- ✅ Mute button visible
- ✅ Responsive design

## Deployment

This project is deployed on Vercel. View it at: https://anam-ai-widget-test.vercel.app/

## Local Development

```bash
# Serve locally
python -m http.server 8000
# or
npx serve .

# Open http://localhost:8000
```
